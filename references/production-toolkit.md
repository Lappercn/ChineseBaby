# 制作工具路由

先检查当前环境，不把本机经验等同于已安装。媒体检查/抽帧可用FFmpeg与scripts/inspect_video.py；带时间码转写可选择本地ASR；剪辑使用同一trim/atrim映射；二维图形与圆窗可用Pillow/Canvas；字幕可用SRT/ASS；编码可用H.264/AAC/yuv420p/faststart。具体依赖需另行配置和运行核验。

软件演示用真实录屏，复杂三维/跟踪/遮挡选择合适的引擎或专业工具。GSAP/Anime.js/Three.js/Remotion/Blender是候选路线，未接入不声称可用。静态图片运动不称生成视频。独立工程保留工具版本、代码、输出和验证证据。
