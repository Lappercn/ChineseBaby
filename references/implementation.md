# 制作约束：合适的引擎、统一的时间轴

进入 `04-production` 时读取本文件，并按 [工具路由](production-toolkit.md) 选择实现。这里定义可验收的运行契约，不提供固定片头、分页结构或通用转场模板。下列三引擎分工适用于实际选用它们的项目，不强制实拍剪辑引入三库。

## 引擎职责与版本

| 引擎 | 控制对象 | 不允许的冲突 |
| --- | --- | --- |
| GSAP | 主时间轴、舞台、DOM空间运动、镜头参数 | 与 Anime.js 同时写同一对象的同一属性 |
| Anime.js | 独立数值代理、SVG路径、群聚交错、几何形变 | 独立自走时间导致暂停后仍变化 |
| Three.js | 场景、材质、粒子、镜头、着色器 | 以渲染帧累计状态而无法回拖 |

为每个动画目标列明控制者。用户明确要求三引擎时必须遵守；不足以独立承担场景的引擎可处理有实际画面作用的局部能力，不能假导入凑数；改变硬约束需用户允许。没有该要求时自行选择适合的组合并记录理由。

实现前锁定具体版本和载入形式，查阅所用版本官方 API。不要混用 Anime.js 不同大版本的创建方法。GSAP 常用秒；Anime.js 要明确所选版本和设置的时间单位；DOM旋转常用度而 Three.js 旋转使用弧度，适配层显式转换。

原稿的弹簧参数 `stiffness: 300, damping: 25, mass: 1` 是运动质感参考，不是三引擎通用参数对象。查清对应实现的参数语义；缓动近似不能标为真实弹簧仿真。

## 主时钟与可寻址渲染

项目时间使用秒表示。主时间轴或媒体主时钟只选一个。实现统一入口 `renderAt(timeSeconds)`：给定时间后，DOM、SVG、Canvas、Three.js、字幕、HUD与素材视频得到对应状态。

- 子动画关闭自主播放，从主时间定位；启动、暂停、变速、回拖均从同一控制器进入。
- 随机粒子与模拟使用固定种子。解析运动直接按绝对时间计算；碰撞模拟使用固定步长与快照/重放恢复。只有固定种子、但继续从当前状态积分，仍然不能正确回拖。
- Three.js 渲染循环只负责把当前状态绘制出来；画面推进不能依赖 `position += velocity` 的帧累加。
- 时间轴回调不负责一次性创建不可逆场景。对象提前建立或由目标时间重建；反向定位不能依赖已执行过的进入事件。
- 无限呼吸动画在有限片长内按周期映射；整片时长不能被无限重复撑成无穷。
- 媒体元数据加载后按镜头区间映射素材局部时间。跳转等待媒体定位，视频长度不足时按已记录的裁切/冻结/循环策略处理。浏览器自动播放与带声变速存在限制，需有用户启动入口并实测。

## 单文件、离线与素材替换

剪片/视频任务交付实际编码文件，交互动画任务交付HTML和控制器。视频的源素材、剪辑配置、字幕与导出文件各自保留，检查全解码、时长、音画和字体；HTML的运行依赖按 brief 中的约定处理：

| 模式 | 封装要求 | 必测 |
| --- | --- | --- |
| 联网单文件 | HTML 可以引用锁定版本 CDN；明确需要联网 | 网络可用及依赖失败时的可见错误 |
| 完全离线单文件 | 所需库、字体、素材打包内嵌；保留必要许可说明 | 禁用网络后重新打开；不得隐含 CDN 或外部资源 |
| 离线目录包 | HTML 与本地依赖同包；仅在用户允许该形式时使用 | 打开方式、本地路径、依赖齐全 |

不能把“只有一个 HTML”自动称为离线，也不能在要求三引擎离线时自行删为原生 CSS。文件较大时说明大小与取舍，不虚构缓存保证。

素材槽位使用稳定 `assetId`，集中登记并提供实际可用的文件选择/替换入口。替换更新图片、视频、纹理和焦点，不能只替换小缩略图。使用对象 URL 时更换和退出均释放旧资源；重新打开后的持久化能力按实际实现说明，不能把临时文件选择称为永久保存。

`manifest.json` 约定：

- 顶层 `schemaVersion`、`assets`；项目初始 `assets` 为空，不代表素材已齐全。
- 每项：`id`、`kind`（image/video/audio）、`status`（provided/placeholder/missing）、`source`（相对路径或明确引用）、`usedBy`（分镜ID）、`fit`（contain/cover）、`focus`（0–1归一化 x/y/width/height）、`timing`（入点/出点）、`notes`。
- 未知值写 `null` 或明确未确认，不能凭空生成文件来源、时长或版权声明。焦点区域要满足边界条件，替换素材后复核。

## 画面与运行质量

- 画幅和逻辑坐标集中配置；保持纵横比。世界层、证据层、字幕/HUD、编辑控制器分层。预览控制器可以隐藏，不能出现在成片画面。
- 字体需验证中文覆盖和缺失时的回退。长句换行、字幕遮挡与竖屏裁切需要实际画面检查。
- 动画优先操作合成友好的属性；控制粒子数量、分辨率、大面积模糊和阴影成本。性能不达标时先减少装饰，不牺牲语义表达。
- 模糊不等于真实折射；fBm纹理不等于物理流体。视觉近似与仿真实现使用准确名称。
- 更改 Three.js 相机投影参数后按所用 API 更新投影；重建场景时释放几何体、材质、纹理及监听器。释放 GSAP/Anime.js 实例，避免替换素材或重播后叠加运行。
- 不以框架名称承诺60 fps。记录目标设备、浏览器、画幅、粒子规模和测量方法；未测则写未验证。

## 官方 API 入口

下列是实现时按具体版本核对的入口，不表示本 harness 锁定了某个库版本：

- [GSAP Timeline](https://gsap.com/docs/v3/GSAP/Timeline/)：时间线与播放控制。
- [Anime.js Timeline](https://animejs.com/documentation/timeline/)：时间线、同步与动画组织。
- [Three.js 文档](https://threejs.org/docs/)：镜头、渲染和资源对象。
