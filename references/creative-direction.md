# 主动创意：从含义扩展表达

用户给出的效果词和参考图是起点，不是创意上限。模型应在理解目标、背景和素材后主动提出更合适的呈现；用户说“加动画”时，也要判断是否应换为证据放大、白板推演、实拍穿插或角色叙事，而不是只往原片叠动效。

## 发散什么，守住什么

可以发散视觉比喻、镜头路线、材料组合、排版、声音衔接、揭示顺序与情绪节奏。事实、说话者观点、事件关系、数字口径和用户明确偏好是依据；新创意不能靠捏造这些成立。原意有缺口时先补背景，不将未知点包装成反转。

## 从内容生长的创意入口

下面是思考方向，不要求逐一使用，也不规定每片必须有多少种。

| 发现的内容机会 | 可以怎样扩展 | 选用前检查 |
| --- | --- | --- |
| 一句抽象关系 | 将关系变成可见空间：包含、分叉、挤压、依赖、累积 | 动作是否真表达关系，还是只是画了一条箭头 |
| 一个真实结果或反差 | 先给可验证结果的局部，再回看过程，最后回到同一结果 | 开场承诺是否能兑现，有没有剪掉关键条件 |
| 用户的一个具体细节 | 放大物件、记录、动作或照片中的线索，让它成为跨镜头锚点 | 素材是否真的包含该细节，焦点是否正确 |
| 同一个对象的不同意义 | 让数字变比例、字形变路径、截图焦点变为下一幕构图锚点 | 观众是否能认出继承对象，数据比例是否守真 |
| 故事中的时间/情绪转折 | 在转折处改变节奏、景别、材质或声音，给结论留停顿 | 是否在真实语义处变化，而非固定间隔震屏 |
| 一个适合幽默化的误解 | 用角色、拼贴、短促反应或字符包袱使误解具象 | 是否符合用户身份/受众，会不会损害原意 |
| 多种真实材料 | 人物建立信任→记录作证→白板解释→实拍落地，各自接力 | 是否每次交接都提供新信息，人物可否暂时退出 |

先找一两个最有潜力的方向，必要时给用户几个可比较的短方案：看点、原句依据、素材、关键镜头及代价。已有授权和清楚内容时可以自行选择继续，不为每个创意增加批准关卡。

## 从发散收束到可拍、可做

用这些问题挑方案：更准确吗？更容易看懂吗？视觉有辨识度吗？能被现有/可获取素材支撑吗？在片长内有阅读和情绪空间吗？所需能力真实可用吗？删除哪种装饰反而更清楚？

对决定质感的镜头先做代表帧和短运动验证，检查转场前/中/后，不只列“弹性、粒子、炫酷”名词。技术不足时按 [工具路由](production-toolkit.md) 寻找能力或调整创意范围，不能将全部镜头降为静态卡片。

## 参考转译而非复刻

研究参考的“为什么有效”：信息层级、实证出现时机、主次交接、反差、角色身份、连续物和运动方向。用本片内容重新组合机制，至少说清与参考的语义差异；不复制参考的账号成绩、台词、品牌、角色或整段画面。

流量表现受选题、受众、账号和分发等因素影响。参考只能帮助形成可验证的创意假设，不能从截图推出某个动效必然提高流量。评价本片先看表达、可信度和注意力是否连贯，再讨论可观察的运营数据。
