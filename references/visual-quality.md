# 可检查的视觉质量标准

用证据与一致性降低模型审美差异，不宣称可以消除主观判断。每条片先确立视觉token，再用代表帧与运动片段验证。

## 视觉规格

在 `01-direction/direction.md` 中落实：

| 维度 | 必须决定 | 检查方式 |
| --- | --- | --- |
| 色彩 | 背景/正文/强调/危险色，控制强调色角色 | 抽取开场/解释/高潮/结尾代表帧，查看颜色是否一致服务语义 |
| 字体 | 中文与拉丁字体、回退、标题/正文/标签层级、字重、行高和换行策略 | 检查真实长句、数字、中英混排；字体未加载前后不能失控 |
| 构图 | 主焦点、逻辑画幅、网格、安全区、留白和字幕区域 | 在目标画幅缩小到实际观看尺寸，检查结论和证据可读性 |
| 材质 | 纸/金属/玻璃/像素的边缘、阴影、噪声、折射程度 | 比较同类对象，避免一幕一种无关材质 |
| 镜头 | 景别、动势、焦点路线、继承物和层间视差 | 看转场前/中/后，能否辨认同一对象如何变化 |
| 动效 | 进入/强调/停留/退出时长，缓动族与运动强度 | 正常速度与慢放比较；检查阅读停留而非只看运动华丽 |
| 信息 | 同屏层级、证据来源、字幕与辅助信息 | 不看口播也能辨认正在强调哪条结论，但不额外制造事实 |

禁止仅填写“高级、丝滑、电影感”作为设计规格；必须转成可实施的字体、间距、位置、层级或时间参数。

## 代表帧先行

在大规模制作前选开场、典型解释、转折/高潮、结尾四类代表构图；短片可合并。先验证字体、留白、材质和焦点，再铺完整时间轴。它们是本片设计草案，不是需要额外用户批准的关卡。

完成后保存同类时刻截图，逐项比较：阅读焦点是否明确、原稿含义是否被视觉表达、参考片学到的机制是否真正出现。静帧通过后还必须检查连续运动；截图不能证明镜头连贯。

## 参考片拆解

若收到本地视频，先在 [参考片研究目录](video-studies/AGENTS.md) 建立观察记录：真实文件、时间码、画面证据、运动机制、推断与可迁移能力。不能只根据文件名或用户描述写“已学习”。

优先学习：同源形变、焦点迁移、字体对比、主次层级、空间分层、连续运动和节拍变化。不要把参考里的主题、logo、角色或已制成的视频画面当作本片原创素材。

## 验收口径

自媒体口播额外检查：选题看点是否来自真实内容，人物/证据/白板/字符/实拍的交替是否增加信息，公开标题/标签是否为用户对观众说的话，AI画面是否解释了原句而非只显得精美。对照 [内容审阅](editorial-review.md) 与 [创意指引](creative-direction.md)，不要用“参考流量高”代替依据。

视觉质量问题按具体影响记录，例如“证据截图倾斜导致数字不可读”“同一人窗在转场中无由跳位”“高潮仍堆满辅助标签”。修复位置分别路由至导演、分镜或制作；不能用笼统的“再美一点”代替修复要求。
