# 五种视觉语言库

将原始五风格总结转为可供导演决策的语言库。先匹配内容，再取参数；参数均为设计起点。四段已提供本地视频的视觉观察见 [研究记录](video-studies/studies.md)；液态玻璃尚无对应视频，相关描述来自用户文字。原消息中其他仅有文件名的引用不能当作已研究素材。

以下五种不是风格上限。浅色白板、干净纪实、角色拼贴或用户已有品牌体系都可作为主风格，按同样标准落实字体、色彩、材质、构图和运动。口播形态先看 [表达选择](narration-styles.md)，新截图示例见 [分层与拼贴研究](reference-stills/studies.md)。

## 1. 暗金极简科普与数据可视化

参考：《运气的形状》。适合历史、概率、数学与抽象知识解释。

- **视觉美学**：深炭黑/暗褐径向渐变 `#0D0C0A → #1A1712`，香槟金 `#D4AF37`、象牙白 `#F5F2EB`。骰子、羊距骨、命运之轮、坛子等对象用1–2px细线、半透明填充和克制外发光表达。避免无关写实贴图。
- **动效物理**：大数定律折线收敛、布丰投针、高尔顿钉板等按数学与模拟驱动。线条、树状图与钟形曲线用路径生长；立方体与十字展开图以几何对应形变连接。可参考 `cubic-bezier(0.22, 1, 0.36, 1)` 的减速质感。
- **排版构图**：思源宋体/Garamond类衬线层级，字号、字重、斜体引文与字距区分信息。左上年份/地点人物，右上文献/印章，底部字幕；中央约70%留给演示。文献出处必须真实可追溯，不能为了装饰编造。
- **叙事效率**：用面积比较、路径分叉、粒子累积解释公式；装饰不得盖过推理过程。
- **代码映射**：Canvas 2D、SVG、分布函数与随机采样，必要时 Three.js 展示空间结构。算法能程序化表达不等于保证百分百复刻参考片；随机与碰撞需支持回拖复现。

## 2. 东方水墨流体与意境转场

参考：《颠倒》。适合东方哲思、聚散、顺逆和空间反转。

- **视觉美学**：宣纸米黄 `#E8E2D5`，微噪点纸纹；凡间使用焦、浓、重、淡、清灰阶，仙境转石青、石绿与泥金。留白遵循“计白当黑”；墨边使用自然羽化、毛刺与水渍渗透。
- **动效物理**：Perlin/Simplex噪声形成扩散、飞溅与游丝汇聚太极漩涡。以水面倒影作分界，空间翻转将倒影升格为云端仙山；180度翻转只用于原稿确有顺逆/颠倒关系的节点。
- **排版构图**：右上锚定，`writing-mode: vertical-rl`，行书/楷书和朱砂印章，文字融入画卷并保留阅读时间。
- **叙事效率**：以聚散表达形气转化，以翻转表达顺逆；将形式与哲学含义绑定，避免只换水墨背景。
- **代码映射**：Three.js/WebGL/GLSL片元着色器、fBm、极坐标与波纹映射。程序噪声是视觉近似；需要真实流体时另行实现仿真并验证成本。

## 3. 液态毛玻璃 UI 动效

参考：《Liquid Glass》。适合产品、触感、控制与连续形变。

- **视觉美学**：淡紫、冰蓝、樱花粉 Mesh Gradient；组件可从 `backdrop-filter: blur(24px)`、`rgba(255,255,255,0.65)`、1px顶部高光起步。环境/接触阴影、边缘高光与折射形成材质层次。
- **动效物理**：高阻尼弹簧质感；圆点分裂成按钮，再展开为圆角播放器，宽高和圆角连续插值。原参考参数 `stiffness: 300, damping: 25, mass: 1` 需转换成所用引擎实际支持的模型。透镜经过文字时可做位移放大、弯曲与色散，普通毛玻璃不等于真实折射。
- **排版构图**：SF Pro/Inter类无衬线与瑞士网格，强字重对比。四角微字号工程参数如 `01 / 08`、`120 BPM`，中央只突出当前核心交互；参数需与内容相符。
- **叙事效率**：Morph、Expand、Refract、Control、Navigate、Measure、Search、Merge是可选语义动作，不能无论文案都套15秒8幕。
- **代码映射**：GSAP共享形变、Anime.js局部数学/路径、Three.js材质或场；SVG `feDisplacementMap` 可作局部效果。React/Tailwind/Framer Motion仅在已有项目或用户选择时采用，不自动替换指定三引擎。

## 4. 复古像素游戏与强节奏叙事

参考：《我和 Codex》。适合说唱、幽默、游戏隐喻与人物成长。

- **视觉美学**：8-bit/16-bit风格，高饱和街机调色板、Dithering与粗黑像素描边。`image-rendering: pixelated` 保护放大的像素素材；Canvas另需控制整数缩放和图像平滑，单写CSS不能制造像素风。
- **动效物理**：角色敲键盘、举论文、欢呼使用低帧率逐帧状态，参考 `steps(2)` 至 `steps(4)`；镜头可平滑移动。金币抛物线、烟花、放射金光对齐奖赏节点。
- **排版构图**：RPG头像、HP/MP、装备格、问号砖、MOBA小地图和技能键按语义选用；底部黑底白框对话系统配点阵字体。横版、RPG对峙、俯视与选人分屏随剧情变化，并保持角色身份与空间方向。
- **叙事效率**：每个视觉包袱对应具体歌词或现实关系，例如机房/厨房、导师/辅助；真实奖项与论文不可在非虚构叙述中凭空添加。
- **代码映射**：二维数组映射颜色、Canvas像素角色与程序化道具；GSAP镜头、Anime.js反馈群组、Three.js空间场。画面内容可程序化，不承诺无需素材即可精确复制任意人物。

## 5. 科技感 MG 包装与教程剪辑

参考：《AI 剪辑》。适合软件演示、流程教学与效率工具。

- **视觉美学**：深黑底、半透明白色正交工程网格，青 `#00FFFF` 与品红 `#FF00FF` 作少量重点色。故障错位只强调爆点，不持续干扰证据阅读。
- **动效物理**：爆发减速可参考 `cubic-bezier(0.16, 1, 0.3, 1)`；速度线与运动模糊服务切入。高潮可短暂RGB通道分离、水平切片错位；人物PiP与全屏录屏通过缩放、移位、压暗调度。
- **排版构图**：Heavy/Black无衬线关键词可占画布60%以上宽度，配真实前后图层穿插。顶部章节条与实际章节匹配；原“引言/安装插件/初剪口播/添加效果/总结流程”是案例，不能强加到其他教程。
- **叙事效率**：开场尽早给出价值与可信证据，中段以演示承载结论。1.5秒换状态、黄金3秒和音效卡点是节奏参考，不保证完播率，也不替代阅读时间。
- **代码映射**：可复用网格、HUD、PiP、字幕与故障能力组件；场景组合仍按原稿设计。已有Remotion/React管线可复用并读取字幕JSON，不为每条片重新造组件，也不把组件复用变成固定分镜。

## 混搭原则

整片统一字体系统、主色、世界尺度和时间控制；跨风格借用动作机制而不是随机换皮。例如暗金概率片可借像素风的离散采样反馈，但不突然出现无关游戏HUD。每次切换都要能对应原稿含义或情绪变化。
