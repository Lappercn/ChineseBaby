# 剪辑与动效经验

用于口播缺少画面、首幕单调、中文动态字、圆形人物调度、多录音拼接及Skill宣传。来自实际制作与返工；下述参数是可调整的起点，不是所有视频的固定配方。

## 先判断表达问题

| 观察到的问题 | 处理选择 | 检查点 |
| --- | --- | --- |
| 开场只有真人和字幕 | 从第0帧建立关键词和主构图，让文字/素材承担开场动作 | 检查0秒及0.3/0.7/1.2秒，避免先空等片头 |
| 人物一直占主舞台 | 在人物、证据、图形、素材间交接，人物可以缩小或暂时退出 | 每次交接是否增加信息 |
| 特效与台词无关 | 先标出动作/关系，再选择对应形状、路径与节奏 | 阻挡对应门槛、阶梯动作对应僵硬、展开对应方案，不假造软件截图 |
| 文字全部同色同大小 | 定义标题/正文/标签层级，强调色用于语义重点 | 小屏可读，不能只靠颜色区分重要含义 |
| 圆窗遮住标签 | 为前景字幕/人物保留占用区域，检查转场全过程 | 不只看人物移动前后的两帧 |
| 新片结尾声音突然变小 | 分别测量并校准不同录音，再拼接，最后测整片响度与峰值 | 整片只做一次响度处理可能保留段间音量落差 |
| 字幕专名错误 | 保留原始ASR、编辑字幕和疑词；以用户纠正和上下文复核 | 不因识别结果重复就认定正确 |

## 动作从语义生长

先将句子对应到视觉功能：情绪→动态字；递进→轨道/对象累积；尝试→路径分支；门槛→遮挡；不满意→未完成结构；僵硬→离散停顿；手动剪→切开；解决方案→流程展开。示意画面明确为示意，不当作其他工具真实输出。

文字可采用0.16–0.28秒短促进入；关键结论留足阅读时间。按词组突出重点，避免长句每字持续弹跳。中文换行用实际字形宽度测量；720×1280画幅可从字幕30–34px、左右28–40px安全区起步。字体、颜色、字号、时间参数集中配置。

## 圆形人物与虚拟镜头

用户要求全程圆形时，所有真实人物图层只经正圆遮罩合成，直径变化仍保持宽高相等。使用高分辨率蒙版缩小抗锯齿；两段不同录制的取景分别复核头顶、眼睛、下巴。位置和直径用同一个绝对时间插值，避免圆窗瞬移或变椭圆。

人物窗只是一种表达选择。单镜头原片可以做真实裁切、景别变化与画布推进，不声称生成了另一真实机位。动效图形和人物、字幕的占用区域要一并检查。

## 拼接与声音

按句尾/音节和波形选择剪点，保留情绪及阅读停顿。音视频使用同一剪辑映射，规范帧率、采样率、声道后拼接。不同录音分别校准后再合并；测量最终集成响度和真实峰值。对白约-16LUFS可作起点，不能替代实际听辨。

## 宣传片与真实对比

先判断宣传对象与表达形态。宣传整个Skill或多类型创作能力时，应读取styles.md，在故事/角色冒险、水墨意境、图形叙事、产品形变等路线中选择。用户已有口播案例不意味着新宣传片仍以口播剪辑为主。可用一个贯穿对象的经历组织痛点、转折和解决方案，让能力直接体现在新片场景中。需要案例实证时才选择真实前后对比；不要把口播案例拼贴当作唯一宣传形态。

可按痛点→同内容前后对比→品牌→能力实证→获取入口组织。对比双方用真实同源内容并明确标签；自制低配示意须注明，不能冒充竞品实测。模型的个人体验不能扩写成普遍性能排名。用实际动态画面证明能力，别只写“特效拉满”。

## 回归与证据

保存首帧、长字幕、素材焦点、圆窗运动中点、拼接前后和结尾；全片解码检查、字幕边界/重叠、音画时长、响度测量分别记录。发布前单独核对片中文字、素材来源及私有路径。连续观看/逐字听辨未做时如实标记预览待验，不能把抽帧等同于完成主观验收。
