# 04 · 制作空间

输入：有效 brief、导演方案、分镜与素材登记。先读 `references/implementation.md`、`references/production-toolkit.md`。输出：本目录的实现、实际视频或 `index.html`，以及 [implementation.md](implementation.md)，以用户交付目标为准。

同时读取 `references/component-reuse.md`、`components/AGENTS.md` 与组件登记。先找已有能力和框架原生效果，记录来源、版本和接入决策；真正缺失时才自定义。

- 在HTML前先向用户给出简短《导演视觉设计阐述》，包括基调/情绪、核心隐喻和素材互动。已在本轮讲清时无需重复长篇文档。
- 围绕本片分镜组织代码；复用基础能力，不套通用片头/分页/转场序列。
- 按 `references/editorial-review.md` 单列观众可见文案及来源；导演自语、处理日志、未经采用的工程名不进入字幕、标题、旁白或封面。生成素材在实际镜头中核对含义，不以精美掩盖错配。
- 先落实本片视觉token与代表构图，核对字体/长句/材质，再扩展时间轴；能力经实际验证后登记为verified。
- 在完整制作前先实现最难且最能代表风格的短镜头，包含入场、主要动作、跟随动作和转场出口；代表帧漂亮但运动僵硬时不能继续批量铺片。
- 集中配置文案、场景、素材ID与布局；每个动画属性只有一个控制者。所有状态服从可定位的项目时间。
- 使用一份共享时间线驱动画面、旁白、字幕、音乐、音效和验收 cue。能独立渲染任意时间点；随机过程固定种子，不依赖上一帧状态。
- 有意义的运动使用预备→动作→跟随/稳定，避免用条件分支瞬间切换姿态。长镜头内部持续改变叙事状态；轻微正弦漂移不能作为主要动作。
- 转场实现风格合同中的媒介语法，并保持对象、运动方向或声音至少一项连续；不得用整幕淡出掩盖无衔接的分页。
- 交互版实现播放、暂停、拖动跳转、重播、时间显示与素材替换；视频版落实帧时钟、剪辑映射和音画同步，播放器操作与交互源码功能分别验收。
- 严格兑现三引擎/离线/单文件等显式要求。遇真实限制时记录并落实可行方案，不能悄悄减项。

出口：代表运动镜头通过短运动检查，完整代码与依赖说明可运行，进入 `05-review`；代码已写完不等于已通过验收。
