# 01 · 导演空间

输入：`00-brief/brief.md`。读取 `references/intent-contract.md`、`references/directing.md`、`references/style-contract.md` 与 `references/styles.md`。输出：[direction.md](direction.md)。

有参考片时先读 `references/video-studies/AGENTS.md` 并提取真实观察；已有研究可复用，缺失镜头证据再补取。读取 `references/visual-quality.md`，把审美要求写成参数与检查点。

- 先提出三种结构差异明确的方案，例如单一旅程、前后对比、倒计时、问题逐层变形；选择一种并说明它为何最能完成意图合同。第一反应通常只是候选，不直接进入制作。
- 为本片写一句主线：一个主体追求什么、遇到什么变化、最后与开头相比发生了什么。产品、物件、观点或人物都可以是主体。
- 按逐句语义提炼动作，选择主风格与情绪曲线。技术参数为创意服务。
- 结合 `references/narration-styles.md` 与 `references/social-editing.md` 选表达形态、真实内容看点和镜头职责交替。人物、证据、白板、动态字、实拍与角色按内容接力，不以人物缩放代替完整导演。
- 按 `references/creative-direction.md` 主动扩展用户的效果提示，形成有原意依据的开场、视觉比喻、素材组合和转场，再按可读性、证据与工具收束；不等用户逐条指定特效。
- AI视觉先填写原句/背景依据、用途、可能暗示的含义，依据 `references/editorial-review.md` 排除主题错配和制作自语。
- 记录至少覆盖核心论点的语义隐喻，并解释为何与原句相符。隐喻数量由内容决定。
- 描述人物、截图和视频如何进入、聚焦、转化与退出，以及跨幕对象。
- 按 `references/production-toolkit.md` 规划真正需要的能力；用户强制的引擎不能自行省略，没有强制时不默认三个库齐上。
- 确定字体/回退/层级、色彩角色、布局安全区、材质与缓动族；规划开场、解释、转折、结尾的代表构图验证，不能只写“高级、丝滑”。
- 写完整风格合同和镜头语法；明确一个贯穿对象、一个媒介原生的标志性镜头、开头与结尾的视觉回响。
- 先选一至两个与本片主题及风格都匹配的标杆，只记录要学习的构图/节奏/镜头/色彩/声音，以及明确不借用的角色、设计、音乐和具体镜头。
- 规划声音：环境底、动作音、音乐状态、两处声音先行或延续的交接；节拍表先于复杂动画。

出口：方案包含意图复述、候选结构与选择、主线、标杆、风格合同、摄影机/转场/声音语法、核心隐喻、素材互动、视觉规格与代表构图验证计划，可转成实际分镜。代表构图的实际渲染验证在04制作开头完成。无需对每阶段再求批准；按已有授权继续。进入 `02-storyboard`。
