# 05 · 验收空间

输入：制作版本、brief、分镜和素材登记。输出：[report.md](report.md)、必要截图与问题修复证据。

## 验收动作

1. **内容**：按 `references/editorial-review.md` 对照原意、前因后果、图文与素材角色；核对逐句覆盖、数据口径、图形比例、引文与素材来源。单独清查全部新增标题/标签/封面/旁白中的制作自语，不只检查字幕。
2. **导演**：通片观看，检查动作是否表达语义、对象继承、镜头方向、快慢差异和素材互动；不能只检查页面能打开。
   按 `references/visual-quality.md` 比较代表帧的字体、构图、材质与焦点；按分镜的参考映射核对学到的机制。检查复用来源和接入证据，不能把候选资源称为已验证组件。
   对每个关键动作生成约 `0.2s` 间隔的帧条，检查预备、接触、跟随和姿态连续；为全片生成每 `1–2s` 一帧的联系表，检查景别、构图与信息密度是否真的变化。
3. **时间**：交互版检查播放/暂停/重播和回拖；例：时长允许时反复 `13s → 2s → 13s`，所有图层状态一致且暂停静止。视频版检查时间映射、剪点、字幕和音轨同步、完整解码及连续观看，不把解码通过写成主观听辨通过。
   核对 cue map：关键动作、剪点、字幕和声音是否落在计划时间；检查字幕读时。长镜头若只有背景漂移、呼吸或无意义循环，判为导演失败并返回02分镜。
4. **素材**：实际替换一张不同比例图片和一个不同时长视频，检查主画面、焦点、纹理、时间映射与资源清理；项目没有视频槽位时明确记为不适用。
5. **运行**：检查加载失败、控制台异常、目标画幅、长字幕、中文字体和窗口变化。离线要求必须禁网重新打开；三引擎要求需证明各自驱动实际效果。
6. **性能**：按目标设备实测；记录方法与观察结果。无法测量则写未验证，不声称60 fps。

每项填写通过/失败/未验证/不适用及理由。没有浏览器工具时可做结构检查，但功能/视觉状态仍应为未验证。

出口：完成至少一次全速带声连续观看，并记录主要问题和一轮集中修复；没有未解决的阻断问题，需求覆盖证据齐全。不能验证时可交付明确标识的预览待验版，并保留本阶段未完成状态。问题按根工作流返工路由处理，修复后重验受影响部分。
