# 02 · 分镜空间

输入：原稿、导演方案与音轨/字幕。输出：[storyboard.md](storyboard.md)。

- 每句原稿必须映射到镜头；同句可跨镜头，多句也可共享连续镜头。
- 补充“已确认含义/背景来源、观众理解目标、素材角色、公开文案依据”。人物/截图/白板/字形/插画的切换应推进叙事，不按固定间隔换模板。
- 为每幕写清时间、动作原语、关系、情绪、空间坐标、继承对象、素材、引擎控制方和验收点。
- 对关键镜头记录参考片时间码/所借机制与候选组件能力。它们是选择依据，不能直接复制整段参考片。
- 检查上一幕出口与下一幕入口，避免同一对象瞬移、动势无由逆转、时间区间重叠而未说明。
- 口播时间不够时调整信息密度与镜头，不擅自删改关键事实。无音轨时保留估算标识。

出口：逐句覆盖、时间连续、每幕动作有语义依据、继承与素材ID可追踪。进入 `03-assets`；以后改分镜需通知制作重验。
